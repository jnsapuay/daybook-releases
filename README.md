# Deibukō releases

Update files for Deibukō, a personal planner for Windows.

This repository holds no source code. Each release carries two files that installed copies of Deibukō read when they check for updates:

- `latest.json` names the newest version and where its update is.
- `Deibuko_<version>_update.bin` is the update itself. It is scrambled, signed, and only opens in an installed copy of Deibukō. It cannot be used to install Deibukō for the first time.

To get Deibukō, ask the person who gave it to you for the installer.
